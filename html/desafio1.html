Desafio meu primeiro HTML

Treinando tags com HTML!

A ideia deste Desafio de Projeto é elaborar um website, utilizando uma estrutura bem básica, utilizando tags aprendidas durante as aulas práticas:

Lista de TAGS

  • h1 - para títulos
  • h2 - para subtítulos
  • p - para paragrafos
  • ul - para listas não ordenadas
  • ol - para listas ordenadas
  • strong - para destacar nomes
  • mark - para grifar texto
  • i - para itálico
  • u - para sublinhar
  • small - destaque em tamanho menor
  • a e blank- para hiperlink e blank para nova aba Google
  • hr - para separação tematica
